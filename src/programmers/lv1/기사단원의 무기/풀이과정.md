# 기사단원의 무기 — 코딩테스트 풀이 기록

| 항목 | 내용 |
|---|---|
| 문제 등급 | Level 1 |
| 문제 플랫폼 | 프로그래머스 |
| 문제 이름 | 기사단원의 무기 / 136798 |
| 알고리즘 | 구현, 시뮬레이션, 약수 |
| 입력 | `int number`, `int limit`, `int power` |
| 시간 복잡도 | 초기 O(N²) → 개선 O(N√N) |
| 예외 케이스 | 완전제곱수, 약수 개수가 제한과 같은 경우 |

**문제 정의**

1. 각 기사는 자신의 번호에 해당하는 약수 개수를 무기의 공격력으로 선택.
2. 약수 개수가 `limit`을 초과하면 공격력을 `power`로 대체.
3. 공격력 1당 철 1kg이 필요하므로 모든 기사의 무기 공격력 합계를 반환.

**엣지 케이스**

- 완전제곱수의 제곱근은 짝이 되는 약수와 같으므로 한 번만 계산.
- 약수 개수가 `limit`과 같으면 그 개수를 공격력으로 사용.

**의사코드**

1. 공격력을 저장할 정수형 배열 `swords`를 길이 `number`로 선언한다.
2. `i`는 1부터 `number` 이하일 때까지 아래 내용을 반복한다. `i`는 1씩 증가한다.
   - 약수 개수 `count`를 0으로 초기화한다.
   - `j`는 1부터 `i` 이하일 때까지 아래 내용을 반복한다. `j`는 1씩 증가한다.
     - `i % j == 0`이면 `count`에 1을 더한다.
   - `count > limit`이면 `count`를 `power`로 갱신한다.
   - `swords[i - 1]`에 `count`를 저장한다.
3. 공격력 합계 `result`를 0으로 초기화한다.
4. `i`는 0부터 `swords.length` 미만일 때까지 아래 내용을 반복한다. `i`는 1씩 증가한다.
   - `result`에 `swords[i]`를 더한다.
5. `result`를 반환한다.

## 1. 초기 풀이

```java
public class KnightWeapon {
    public int solution(int number, int limit, int power) {
        int[] swords = new int[number];

        for (int i = 1; i <= number; i++) {
            int count = 0;

            for (int j = 1; j <= i; j++) {
                if (i % j == 0) {
                    count++;
                }
            }

            if (count > limit) {
                count = power;
            }

            swords[i - 1] = count;
        }

        int result = 0;

        for (int i = 0; i < swords.length; i++) {
            result += swords[i];
        }

        return result;
    }
}
```

## 2. 문제

- 기사 번호마다 1부터 해당 번호까지 순회. 최대 입력에서는 약 50억 번의 약수 검사가 필요하므로 검사 범위를 줄일 필요가 있다고 판단.
- 약수는 `j`와 `i / j`가 쌍을 이루므로 제곱근까지 검사하고, 두 약수가 같은 경우에는 한 번만 계산.
- 최종적으로 필요한 값은 공격력 합계이므로 각 공격력을 계산한 뒤 `result`에 바로 더함.

## 3. 성능 분석

- `N`은 기사단원 수 `number`.
- 초기 풀이의 약수 검사 횟수는 `1 + 2 + … + N = N(N + 1) / 2`이므로 **O(N²)**. `N = 100,000`이면 5,000,050,000회 검사.
- 최종 풀이에서는 각 기사 번호의 제곱근까지만 검사. 기사 한 명당 최대 `√N`번 검사하므로 전체 시간 복잡도는 **O(N√N)**.

## 4. 최종 수정 코드

**개선 의사코드**

1. 공격력 합계 `result`를 0으로 초기화한다.
2. `i`는 1부터 `number` 이하일 때까지 아래 내용을 반복한다. `i`는 1씩 증가한다.
   - 약수 개수 `count`를 0으로 초기화한다.
   - `j`는 1부터 `j * j <= i`인 동안 아래 내용을 반복한다. `j`는 1씩 증가한다.
     - `i % j == 0`이면 `count`에 1을 더한다.
       - `j * j != i`이면 짝이 되는 약수를 세기 위해 `count`에 1을 더한다.
   - `count > limit`이면 `count`를 `power`로 갱신한다.
   - `result`에 `count`를 더한다.
3. `result`를 반환한다.

```java
public class KnightWeapon {
    public int solution(int number, int limit, int power) {
        int result = 0;

        for (int i = 1; i <= number; i++) {
            int count = 0;

            for (int j = 1; j * j <= i; j++) {
                if (i % j == 0) {
                    count++;

                    if (j * j != i) {
                        count++;
                    }
                }
            }

            if (count > limit) {
                count = power;
            }
            result += count;
        }

        return result;
    }
}
```

**학습 내용**

- 약수의 짝을 이용하면 제곱근까지만 검사해도 전체 약수의 개수를 구할 수 있다.
- 완전제곱수의 제곱근은 자기 자신과 짝을 이루므로 한 번만 계산한다.
- 합계만 필요한 경우 각 값을 계산한 뒤 누적 변수에 바로 더할 수 있다.
