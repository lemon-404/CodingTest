**문제 정의**
1. 문자열에 포함된 정수의 최솟값과 최댓값 탐색
2. `최솟값 최댓값` 형식의 문자열 반환

## 1. 초기 풀이

**접근 방법:**
- 문자열을 공백으로 분리하고 정수를 순회하며 최솟값·최댓값 갱신

## 3. 최종 수정 코드

```java
public class MinimumAndMaximum {
    public String solution(String s) {
        String answer = "";

        int maximum=Integer.MIN_VALUE;
        int minimum=Integer.MAX_VALUE;

        String[] split = s.split(" ");

        for (int i = 0; i < split.length; i++) {
            int n = Integer.parseInt(split[i]);

            if (n > maximum) {
                maximum = n;
            }
            if (n < minimum) {
                minimum=n;
            }
        }
        answer = String.format("%d %d", minimum, maximum);  //String format하는 방법 잘 기억이 안낫음  String.format() 또는 minimum + " " + maximum 사용 가능
        return answer;
    }
}
```

**학습 내용:**
- 문자열 조합: `String.format("%d %d", minimum, maximum)` 또는 문자열 연결 사용
