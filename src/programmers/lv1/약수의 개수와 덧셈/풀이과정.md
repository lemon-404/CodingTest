# 약수의 개수와 덧셈 — 코딩테스트 풀이 기록

| 항목 | 내용 |
|---|---|
| 문제 등급 | Level 1 |
| 문제 플랫폼 | 프로그래머스 |
| 문제 이름 | 약수의 개수와 덧셈 / 77884 |
| 알고리즘 | 구현, 수학 |
| 입력 | `int left`, `int right` |
| 시간 복잡도 | 초기 O(N√M) → 개선 O(N) |
| 예외 케이스 | 없음 |

**문제 정의**

1. `left`부터 `right`까지 양 끝을 포함해 모든 정수를 확인.
2. 약수의 개수가 짝수인 수는 더하고, 홀수인 수는 빼서 결과를 반환.

**의사코드**

1. 결과를 저장할 변수 `result`를 0으로 초기화한다.
2. `i`는 `left`부터 `right` 이하일 때까지 아래 내용을 반복한다. `i`는 1씩 증가한다.
   - 약수 개수 `count`를 0으로 초기화한다.
   - `j`는 1부터 `j * j <= i`인 동안 아래 내용을 반복한다. `j`는 1씩 증가한다.
     - `i % j == 0`이면 `count`에 1을 더한다.
       - `j * j != i`이면 짝이 되는 약수를 세기 위해 `count`에 1을 더한다.
   - `count`가 짝수이면 `result`에 `i`를 더하고, 홀수이면 뺀다.
3. `result`를 반환한다.

## 1. 초기 풀이

```java
public class DivisorCountAndSum {
    public int solution(int left, int right) {
        int result = 0;

        for (int i = left; i <= right; i++) {
            int count = 0;

            for (int j = 1; j * j <= i; j++) {
                if (i % j == 0) {
                    count++;

                    if (j * j != i) {
                        count++;
                    }
                }
            }

            if (count % 2 == 0) {
                result += i;
            } else {
                result -= i;
            }
        }

        return result;
    }
}
```

## 2. 문제

- 초기 풀이에서는 약수 개수의 홀짝을 판단하기 위해 각 정수의 약수 개수를 직접 계산.
- 완전제곱수가 아닌 수의 약수는 모두 서로 다른 짝을 이루므로 약수 개수가 짝수. 완전제곱수는 제곱근이 자기 자신과 짝을 이루어 약수 개수가 홀수.
- `Math.sqrt()`로 완전제곱수 여부를 판별해 내부 반복문과 `count` 변수를 제거.

## 3. 성능 분석

- `N = right - left + 1`은 탐색할 정수의 개수, `M = right`는 탐색 범위의 최댓값.
- 초기 풀이의 내부 반복문은 정수 `i`마다 `⌊√i⌋`번 실행되므로 전체 시간 복잡도의 상한은 **O(N√M)**.
- 최종 풀이에서는 정수마다 제곱근을 한 번 계산해 완전제곱수인지 판단하므로 **O(N)**.
- 범위가 1~1,000일 때 초기 풀이의 내부 반복문은 총 20615회 실행.
- 반복 횟수와 시간 복잡도에 대한 이론적 분석.

## 4. 최종 수정 코드

**개선 의사코드**

1. 결과를 저장할 변수 `result`를 0으로 초기화한다.
2. `i`는 `left`부터 `right` 이하일 때까지 아래 내용을 반복한다. `i`는 1씩 증가한다.
   - `Math.sqrt(i)`의 반환값을 `int`로 변환해 `sqrt`에 저장한다.
   - `sqrt * sqrt == i`이면 `result`에서 `i`를 뺀다.
   - 그 외에는 `result`에 `i`를 더한다.
3. `result`를 반환한다.

```java
public class DivisorCountAndSum {
    public int solution(int left, int right) {
        int result = 0;

        for (int i = left; i <= right; i++) {
            int sqrt = (int) Math.sqrt(i);

            if (sqrt * sqrt == i) {
                result -= i;
            } else {
                result += i;
            }
        }

        return result;
    }
}
```

**학습 내용**

- 약수의 대칭성을 활용하면 제곱근까지만 탐색하여 약수의 개수를 구할 수 있다.
- 완전제곱수의 약수 개수는 홀수이고, 그 외의 양의 정수는 약수 개수가 짝수이다.
- `Math.sqrt()`는 제곱근을 `double`로 반환한다.
- 약수 개수의 홀짝만 필요할 때는 완전제곱수 여부를 판별해 약수 탐색을 생략할 수 있다.
