# 문자열 내림차순으로 배치하기 — 코딩테스트 풀이 기록

| 항목 | 내용 |
|---|---|
| 문제 등급 | Level 1 |
| 문제 플랫폼 | 프로그래머스 |
| 문제 이름 | 문자열 내림차순으로 배치하기 / 12917 |
| 알고리즘 | 구현, 정렬 |
| 입력 | `String s` |
| 시간 복잡도 | O(N log N) |
| 예외 케이스 | 이미 내림차순으로 정렬된 문자열 |

**문제 정의**

1. 문자열 `s`의 문자를 큰 값부터 작은 값 순으로 정렬해 반환.
2. 대문자는 소문자보다 작은 값으로 간주.

**엣지 케이스**

- 이미 내림차순으로 정렬된 문자열은 입력과 같은 순서로 반환.

**의사코드**

1. 문자열 `s`를 `char[]`로 변환한다.
2. `Arrays.sort()`를 사용하여 오름차순으로 정렬한다.
3. `StringBuilder.reverse()`를 사용하여 내림차순으로 변경한다.
4. 문자열로 변환하여 반환한다.

## 3. 성능 분석

- `N`은 문자열 `s`의 길이.

| 연산 | 시간 복잡도 |
|---|---|
| `toCharArray()` | O(N) |
| `Arrays.sort()` | O(N log N) |
| `new String(arr)` | O(N) |
| `StringBuilder` 생성 | O(N) |
| `reverse()` | O(N) |
| `toString()` | O(N) |

- 정렬이 전체 비용을 지배하므로 시간 복잡도는 **O(N log N)**.

## 풀이 코드

```java
import java.util.Arrays;

public class SortStringDescending {
    public String solution(String s) {
        char[] arr = s.toCharArray();
        Arrays.sort(arr);

        String result = new StringBuilder(new String(arr))
                .reverse()
                .toString();

        return result;
    }
}
```

**학습 내용**

- 영문 대문자의 유니코드 값은 65~90이고, 영문 소문자는 97~122이다.
- `String`에는 문자를 직접 정렬하는 메서드가 없다.
- `Arrays.sort()`는 기본적으로 오름차순으로 정렬한다.
- `Arrays.sort(arr, Collections.reverseOrder())`처럼 비교자를 받는 오버로드는 `Integer[]`, `Character[]` 같은 참조형 배열에 적용한다. `int[]`, `char[]`는 기본형 배열이다.
- `StringBuilder.reverse()`로 문자열의 순서를 뒤집을 수 있다.
