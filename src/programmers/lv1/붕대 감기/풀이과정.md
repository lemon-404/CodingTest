# 붕대 감기 — 코딩테스트 풀이 기록

| 항목 | 내용 |
|---|---|
| 문제 등급 | Level 1 |
| 문제 플랫폼 | 프로그래머스 |
| 문제 이름 | 붕대 감기 / 250137 |
| 알고리즘 | 구현(시뮬레이션) |
| 입력 | `int[] bandage`, `int health`, `int[][] attacks` |
| 시간 복잡도 | <span style="color:#D32F2F">**초기 O(T) → 개선 O(M)**</span> |
| 예외 케이스 | 체력 0 이하 시 즉시 -1 반환, 회복 시 최대 체력 제한 |

**문제 정의**
1. `bandage = [t, x, y]`: 매초 x 회복, t초 연속 성공 시 y 추가 회복
2. 공격 시 해당 초 회복 없이 공격력만큼 체력 감소 및 연속 성공 시간 초기화
3. 체력 0 이하 시 사망 처리 및 -1 반환
4. 회복 후 체력을 최대 체력 `health` 이하로 제한
5. 모든 공격 종료 시 남은 체력 반환

**엣지 케이스**
- 공격으로 체력 0 이하 도달 시 즉시 -1 반환
- 기본·추가 회복량이 최대 체력을 초과하면 `health`로 제한
- 최대 체력에서도 연속 성공 시간 `ct` 증가
- `ct == bandage[0]` 도달 시 기본 회복과 추가 회복 적용 후 `ct` 초기화
- 마지막 공격에서 사망하는 경우에도 -1 반환

**의사코드**

1. 현재 체력을 저장할 변수 `hp`를 선언하고 `health`로 초기화한다.
2. 연속 성공 시간을 저장할 변수 `ct`와 공격 순서를 나타낼 변수 `i`를 선언하고 각각 0으로 초기화한다.
3. 마지막 공격 시간을 저장할 변수 `end`를 선언하고 `attacks[attacks.length - 1][0]`을 저장한다.
4. 반복문 `t`는 1부터 `t <= end`까지 1씩 증가시키며 아래 작업을 반복한다.
   - `attacks[i][0]`과 `t`가 다른지 확인한다.
   - 공격 시간이 아니면 아래 작업을 수행한다.
     - `hp`에 `Math.min(health, hp + bandage[1])`을 저장한다.
     - `ct`를 1 증가시킨다.
     - `ct == bandage[0]`이면 아래 작업을 수행한다.
       - `hp`에 `Math.min(health, hp + bandage[2])`를 저장한다.
       - `ct`를 0으로 초기화한다.
   - 공격 시간이면 아래 작업을 수행한다.
     - `ct`를 0으로 초기화한다.
     - `hp`에서 `attacks[i][1]`만큼 감소시킨다.
     - `i`를 1 증가시킨다.
     - `hp <= 0`이면 -1을 반환한다.
5. 반복문이 종료되면 `hp`를 반환한다.

## 1. 초기 구현

```java
class BandageHealing {
    public int solution(int[] bandage, int health, int[][] attacks) {
        int hp = health;
        int ct = 0;
        int i = 0;
        int end = attacks[attacks.length - 1][0];

        for (int t = 1; t <= end; t++) {
            if (attacks[i][0] != t) {
                hp = Math.min(health, hp + bandage[1]);
                ct++;

                if (ct == bandage[0]) {
                    hp = Math.min(health, hp + bandage[2]);
                    ct = 0;
                }
            } else {
                ct = 0;
                hp -= attacks[i][1];
                i++;

                if (hp <= 0) {
                    return -1;
                }
            }
        }

        return hp;
    }
}
```

## 2. 성능 분석

**복잡도:**
- `T`: 마지막 몬스터 공격 시간
- `M`: 몬스터 공격 횟수, `attacks.length`
- 초기 시간 복잡도: O(T) — 마지막 공격 시간까지 매초 O(1) 처리
- 개선 시간 복잡도: O(M) — 각 공격마다 회복·피해를 O(1) 처리
- 두 풀이의 추가 공간 복잡도: O(1) — 고정 개수 변수 사용

## 3. 문제점 및 개선 방향

- 처음에는 마지막 공격 시간까지 1초씩 진행하며 공격 여부와 회복량을 처리
- 실제 시간이 흐르기를 기다리는 상황이 아니라, 공격 시점이 이미 모두 주어진 시뮬레이션이라는 점에 주목
- 이미 공격 기록을 알고 있는데도 모든 시간을 1초씩 순회해야 하는지 재검토
- 공격 사이의 시간 차이로 기본 회복량과 추가 회복 횟수를 한 번에 계산하는 방식으로 전환
- 공격 시 연속 성공 시간이 초기화되므로 각 공격 구간 독립 처리
- 마지막 공격 시간까지의 O(T) 반복을 공격 횟수만큼의 O(M) 반복으로 개선

### 3-1. 개선 의사코드

1. 현재 체력을 저장할 변수 `hp`를 선언하고 `health`로 초기화한다.
2. 마지막 공격 시간을 저장할 변수 `t`를 선언하고 0으로 초기화한다.
3. 반복문 `i`는 0부터 `i < attacks.length`까지 1씩 증가시키며 아래 작업을 반복한다.
   - 회복 가능 시간을 저장할 변수 `h1`을 선언하고 `attacks[i][0] - t - 1`을 저장한다.
   - 추가 회복 횟수를 저장할 변수 `h2`를 선언하고 `h1 / bandage[0]`을 저장한다.
   - `t`에 `attacks[i][0]`을 저장하여 마지막 공격 시간을 갱신한다.
   - `hp`에 `Math.min(health, hp + h1 * bandage[1])`을 저장하여 기본 회복을 적용한다.
   - `hp`에 `Math.min(health, hp + h2 * bandage[2])`를 저장하여 추가 회복을 적용한다.
   - `hp`에서 `attacks[i][1]`만큼 감소시킨다.
   - `hp <= 0`이면 -1을 반환한다.
4. 반복문이 종료되면 `hp`를 반환한다.

## 4. 최종 수정 코드

```java
public class BandageHealing {
    public int solution(int[] bandage, int health, int[][] attacks) {
        int hp = health;
        int t = 0;

        for (int i = 0; i < attacks.length; i++) {
            int h1 = attacks[i][0] - t - 1;
            int h2 = h1 / bandage[0];

            t = attacks[i][0];

            hp = Math.min(health, hp + h1 * bandage[1]);
            hp = Math.min(health, hp + h2 * bandage[2]);

            hp -= attacks[i][1];

            if (hp <= 0) {
                return -1;
            }
        }

        return hp;
    }
}
```

| 추가 공간 복잡도 | O(1) | O(1) |
