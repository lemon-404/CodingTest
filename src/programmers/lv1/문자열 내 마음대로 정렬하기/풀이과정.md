# 문자열 내 마음대로 정렬하기 — 코딩테스트 풀이 기록

| 항목 | 내용 |
|---|---|
| 문제 등급 | Level 1 |
| 문제 플랫폼 | 프로그래머스 |
| 문제 이름 | 문자열 내 마음대로 정렬하기 (12915) |
| 알고리즘 | 구현, 정렬 |
| 입력 | `String[] strings`, `int n` |
| 시간 복잡도 | 최악 `O(N log N × L)` |
| 예외 케이스 | 인덱스 `n`의 문자가 같은 문자열 |

**문제 정의**

1. 문자열 배열 `strings`와 기준 인덱스 `n`이 주어짐.
2. 각 문자열의 인덱스 `n`에 있는 문자를 기준으로 오름차순 정렬.
3. 기준 문자가 같으면 문자열 전체를 기준으로 사전순 정렬한 뒤 결과 배열 반환.

**엣지 케이스**

- `["abce", "abcd", "cdx"]`, `n = 2`에서 `"abce"`와 `"abcd"`의 기준 문자는 모두 `'c'`. 전체 문자열의 사전순을 적용한 결과는 `["abcd", "abce", "cdx"]`.

**접근 방법**

1. `Map`을 활용한 문자열 정렬
   - 문자열을 키로, 인덱스 `n`의 문자를 값으로 저장하는 방식 검토.
   - 항목을 정렬한 뒤 키를 순서대로 결과 배열에 저장.
   - `Map` 구현체의 순회 순서와 중복 문자열이 같은 키로 합쳐지는 문제를 고려.

2. `Comparator` 람다식을 활용한 문자열 정렬 (확정)
   - `Arrays.sort()`를 사용해 입력 배열 `strings`를 직접 정렬.
   - 람다식에서 인덱스 `n`의 문자를 먼저 비교하고, 같으면 문자열 전체를 사전순으로 비교.

**의사코드**

1. `Arrays.sort()`에 두 문자열 `a`와 `b`를 비교하는 람다식을 전달해 `strings`를 정렬한다.
   - `a.charAt(n)`과 `b.charAt(n)`이 같으면 `a.compareTo(b)`를 반환한다.
   - 두 문자가 다르면 `a.charAt(n) - b.charAt(n)`을 반환한다.
2. 정렬된 `strings`를 반환한다.

## 3. 성능 분석

- `N`은 문자열 개수, `L`은 가장 긴 문자열의 길이.
- 초기 추정은 `O(N)`. 정렬의 비교 횟수와 `compareTo()`의 비용을 반영해 최악 `O(N log N × L)`로 재분석.
- 객체 배열 정렬의 최악 비교 횟수는 `O(N log N)`. `charAt(n)`은 `O(1)`이고, 기준 문자가 같을 때 수행하는 `compareTo()`는 공통 접두사의 길이에 따라 한 번에 최대 `O(L)`.

## 풀이 코드

```java
import java.util.Arrays;

public class SortStringsByIndex {
    public String[] solution(String[] strings, int n) {
        Arrays.sort(strings, (a, b) -> {
            if (a.charAt(n) == b.charAt(n)) {
                return a.compareTo(b);
            }

            return a.charAt(n) - b.charAt(n);
        });

        return strings;
    }
}
```

**학습 내용**

- `HashMap`은 순회 순서를 보장하지 않음. `LinkedHashMap`은 기본적으로 삽입 순서를, `TreeMap`은 키의 정렬 순서를 따름.
- `Arrays.sort()`, `List.sort()`, `Collections.sort()`에 비교 기준 지정 가능.
- `Comparator`의 반환값이 음수면 `a`가 앞, 양수면 `b`가 앞, 0이면 두 값의 정렬 우선순위가 같음.
- 문자 비교는 오름차순에서 `a.charAt(n) - b.charAt(n)`, 내림차순에서 `b.charAt(n) - a.charAt(n)` 사용.
- 문자열 비교는 오름차순에서 `a.compareTo(b)`, 내림차순에서 `b.compareTo(a)` 사용.
- 비교 기준이 여러 개면 앞선 기준이 동률일 때 다음 기준을 적용.
