# 데이터 분석 — 코딩테스트 풀이 기록

| 항목 | 내용 |
|---|---|
| 문제 등급 | Level 1 |
| 문제 플랫폼 | 프로그래머스 |
| 문제 이름 | [PCCE 기출문제] 10번 / 데이터 분석 (250121) |
| 알고리즘 | 구현, 정렬, 필터링 |
| 입력 | `int[][] data`, `String ext`, `int val_ext`, `String sort_by` |
| TreeSet 삽입 시간 복잡도 | `O(L log N)` |
| 예외 케이스 | 기준값과 같은 행, 필터링 결과가 없는 경우 |

**문제 정의**

- `data`의 각 행은 `code`, `date`, `maximum`, `remain` 순서로 구성.
- `ext` 열의 값이 `val_ext`보다 작은 행을 추출.
- 추출한 행을 `sort_by` 열 기준으로 오름차순 정렬해 반환.

**엣지 케이스**

- 값이 `val_ext`와 같은 행은 제외.
- 필터링 결과가 없으면 빈 2차원 배열 반환.
- `ext`와 `sort_by`가 같으면 같은 열로 필터링하고 정렬.

**의사코드**

1. `Map<String, Integer>`에 `code`, `date`, `maximum`, `remain`을 각각 `0`, `1`, `2`, `3`에 매핑한다.
2. `sort_by`에 해당하는 인덱스를 `sortIndex`에 저장한다.
3. 람다 표현식으로 `sortIndex` 열을 비교하는 `TreeSet<int[]>`을 생성한다.
4. `i`는 `0`부터 `data.length` 미만일 때까지 아래 내용을 반복한다. `i`는 `1`씩 증가한다.
   - `data[i][map.get(ext)]`를 `fragment`에 저장한다.
   - `fragment < val_ext`이면 `data[i]`를 `TreeSet`에 추가한다.
5. `TreeSet`을 2차원 정수 배열로 변환해 반환한다.

## 3. 성능 분석

- `N`은 전체 행 수, `L`은 필터링 조건을 만족하는 행 수.
- 전체 행 순회는 `O(N)`, `TreeSet` 삽입은 `O(L log N)`, 결과 배열 변환은 최대 `O(L)`.
- 순회를 포함한 전체 시간 복잡도는 `O(N + L log N)`.

## 풀이 코드

```java
import java.util.*;

public class DataAnalysis {
    public int[][] solution(int[][] data, String ext,
                            int val_ext, String sort_by) {

        Map<String, Integer> map = new HashMap<>();
        map.put("code", 0);
        map.put("date", 1);
        map.put("maximum", 2);
        map.put("remain", 3);

        int sortIndex = map.get(sort_by);

        TreeSet<int[]> set = new TreeSet<>(
            Comparator.comparingInt(arr -> arr[sortIndex])
        );

        for (int i = 0; i < data.length; i++) {
            int fragment = data[i][map.get(ext)];

            if (fragment < val_ext) {
                set.add(data[i]);
            }
        }

        return set.toArray(new int[0][]);
    }
}
```

**학습 내용**

- `TreeSet`은 원소를 추가할 때 정렬 순서를 유지할 수 있다.
- `ArrayList`는 원소를 모은 뒤 `sort()`로 정렬할 수 있다.
