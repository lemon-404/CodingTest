# 동영상 재생기 — 코딩테스트 풀이 기록

| 항목 | 내용 |
|---|---|
| 문제 등급 | Level 1 |
| 문제 플랫폼 | 프로그래머스 |
| 문제 이름 | [PCCP 기출문제] 1번 / 동영상 재생기 (340213) |
| 알고리즘 | 구현, 시뮬레이션 |
| 입력 | `String video_len`, `String pos`, `String op_start`, `String op_end`, `String[] commands` |
| 시간 복잡도 | **초기 설계 O(N) → 최종 O(N)** |
| 예외 케이스 | 오프닝 구간 진입, 0초 미만 이동, 영상 길이 초과 이동 |

**문제 정의**

1. `prev`로 10초 전, `next`로 10초 후 이동 및 오프닝 자동 건너뛰기 제공
2. 시작 위치와 명령어 배열을 기준으로 재생 위치를 갱신하고 최종 위치를 `mm:ss` 형식으로 반환

**엣지 케이스**

- 초기 위치가 오프닝 구간에 포함되면 오프닝 종료 위치로 이동
- 명령어 실행 후 오프닝 구간에 포함되면 종료 위치로 이동, 시작점·끝점 포함
- `prev` 실행 후 0초 미만이면 0초로 보정
- `next` 실행 후 영상 길이 초과 시 마지막 위치로 보정

**의사코드**

1. 시간을 초로 변환하는 `toSeconds(String format)`을 구현한다.
   - `mm:ss` 문자열을 `split(":")`으로 분리한다.
   - 분과 초를 `Integer.parseInt()`로 변환한다.
   - `분 * 60 + 초`를 반환한다.
2. 초를 시간 문자열로 변환하는 `toFormat(int seconds)`를 구현한다.
   - `seconds / 60`으로 분을 계산한다.
   - `seconds % 60`으로 초를 계산한다.
   - `String.format("%02d:%02d", mm, ss)`로 문자열을 반환한다.
3. 오프닝을 건너뛰는 `skipOpening(int now, int ops, int ope)`를 구현한다.
   - `ops <= now && now <= ope`이면 `now = ope`로 갱신한다.
   - `now`를 반환한다.
4. 초기 위치와 영상 정보를 설정한다.
   - `pos`, `op_start`, `op_end`, `video_len`을 초로 변환하여 각각 `now`, `ops`, `ope`, `limit`에 저장한다.
   - `now = skipOpening(now, ops, ope)`를 실행한다.
5. `i`는 0부터 `commands.length` 미만일 때까지 아래 내용을 반복한다. `i`는 1씩 증가한다.
   - `switch(commands[i])`로 명령어를 구분한다.
   - `next`이면 `now += 10` 후 `now > limit`일 때 `now = limit`으로 보정한다.
   - `prev`이면 `now -= 10` 후 `now < 0`일 때 `now = 0`으로 보정한다.
   - 매 명령어 처리 후 `now = skipOpening(now, ops, ope)`를 실행한다.
6. `toFormat(now)`의 반환값을 `result`에 저장하고 반환한다.

## 1. 초기 구현

- 별도의 초기 Java 코드 없이 의사코드로 먼저 설계
- 입력 시간을 초 단위 정수로 변환하고 최종 결과를 `mm:ss` 형식으로 복원하는 방식 구상
- 오프닝 검사 메서드 분리 및 `switch-case` 명령어 처리 설계
- 위 의사코드에는 검토 과정에서 보완한 범위 보정·매 명령 후 오프닝 검사 포함

## 2. 성능 분석

- `N = commands.length`
- 각 명령어 처리와 오프닝 검사: O(1)
- 입력 시간 문자열: 고정된 `mm:ss` 형식, 시간 변환 O(1)
- 전체 시간 복잡도: O(N)
- 초기 복잡도: 실행 코드가 아닌 설계 기준

## 3. 문제점 및 개선 방향

- 의사코드 검토 중 명령어 실행 후 범위 보정과 오프닝 건너뛰기 누락 가능성 발견
- 실제 제출 오류·시간 초과 발생 기록 없음
- 처음에는 시작 위치에서만 오프닝 구간 검사
- 초기 명령어 처리 설계에 `next`·`prev` 실행 후 범위 보정 미반영
- 오프닝 검사를 마지막에 한 번만 수행하면 명령어 사이의 자동 건너뛰기 누락 가능
- `next`·`prev` 분기 안에서 각각 영상 끝·0초 경계 보정
- 매 명령어 실행 후 `skipOpening()` 호출
- 반복되는 오프닝 검사 로직을 별도 메서드로 추출

## 4. 최종 수정 코드

```java
public class VideoPlayer {
    public String solution(String video_len, String pos, String op_start, String op_end, String[] commands) {
        int now = toSeconds(pos);
        int ops = toSeconds(op_start);
        int ope = toSeconds(op_end);
        int limit = toSeconds(video_len);

        now = skipOpening(now, ops, ope);

        for (int i = 0; i < commands.length; i++) {
            switch (commands[i]) {
                case "next":
                    now += 10;
                    if (now > limit) {
                        now = limit;
                    }
                    break;

                case "prev":
                    now -= 10;
                    if (now < 0) {
                        now = 0;
                    }
                    break;
            }

            now = skipOpening(now, ops, ope);
        }

        String result = toFormat(now);
        return result;
    }

    private int toSeconds(String format) {
        String[] time = format.split(":");

        int mm = Integer.parseInt(time[0]);
        int ss = Integer.parseInt(time[1]);

        return mm * 60 + ss;
    }

    private String toFormat(int seconds) {
        int mm = seconds / 60;
        int ss = seconds % 60;

        return String.format("%02d:%02d", mm, ss);
    }

    private int skipOpening(int now, int ops, int ope) {
        if (now >= ops && now <= ope) {
            now = ope;
        }

        return now;
    }
}
```

|---|---|---|
| 주요 접근 | 초 단위 변환 및 switch-case 중심의 초기 의사코드 | 범위 보정과 매 명령 후 오프닝 건너뛰기를 반영한 구현 |
| 시간 복잡도 | O(N), 설계 기준 | O(N) |

**학습 내용:**

- 순차 명령어 시뮬레이션에서 각 명령어 직후 적용할 규칙 확인 필요
- 명령어 분기 안에서 경계값 보정 가능
- 반복되는 오프닝 건너뛰기를 `skipOpening()` 메서드로 분리
- `String.format("%02d:%02d", mm, ss)`로 앞자리를 0으로 채운 두 자리 형식 유지
