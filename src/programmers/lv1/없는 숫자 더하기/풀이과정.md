# 없는 숫자 더하기 — 코딩테스트 풀이 기록

| 항목 | 내용 |
|---|---|
| 문제 등급 | Level 1 |
| 문제 플랫폼 | 프로그래머스 |
| 문제 이름 | 없는 숫자 더하기 / 86051 |
| 알고리즘 | 배열, 구현, 수학 |
| 입력 | `int[] numbers` — 0~9 사이 서로 다른 숫자, 길이 1~9 |
| 시간 복잡도 | <span style="color:#D32F2F">**초기 O(N + 20) = O(N) → 개선 O(N)**</span> |
| 예외 케이스 | 주어진 입력 조건 외 별도 예외 처리 없음 |

**문제 정의**
1. 0부터 9까지의 숫자 중 일부를 `numbers` 배열로 입력
2. `numbers`에 없는 숫자를 모두 더한 값 반환

**엣지 케이스**
- 길이 9: `[1, 2, 3, 4, 5, 6, 7, 8, 9]` → `0`
- 중복 숫자·빈 배열: 문제 입력 조건에서 제외

## 1. 초기 풀이

**접근 방법:**
- 크기 10인 배열에 0부터 9까지 저장
- `numbers`의 숫자를 인덱스로 사용하여 해당 배열 값을 0으로 변경
- 배열에 남은 값을 합산하여 반환
- 아래 코드: 초기 구상에 따른 예시, 실제 제출한 초기 코드 아님

```java
class SumMissingNumbers {
    public int solution(int[] numbers) {
        int[] array = new int[10];
        for (int i = 0; i < 10; i++) {
            array[i] = i;
        }

        for (int i = 0; i < numbers.length; i++) {
            array[numbers[i]] = 0;
        }

        int answer = 0;
        for (int i = 0; i < array.length; i++) {
            answer += array[i];
        }
        return answer;
    }
}
```

## 2. 문제 및 성능 분석

**발생한 문제:**
- 정답 계산 로직의 오류 없음
- 불필요한 배열 생성 및 초기화·합산 반복 존재

**원인:**
- 0~9를 직접 저장하고 주어진 숫자를 제거한 뒤 합산하는 설계

**복잡도:**
- `N = numbers.length`
- 초기 시간 복잡도: 배열 초기화 10회 + 입력 순회 N회 + 배열 합산 10회 → O(N + 20) = O(N)
- 초기 추가 공간 복잡도: 크기 10인 고정 배열 → O(1)
- 개선 시간 복잡도: 입력 배열 1회 순회 → O(N)
- 개선 추가 공간 복잡도: 정수 변수 사용 → O(1)

**개선 방향:**
- 0부터 9까지의 합인 45 활용
- 45에서 주어진 숫자를 하나씩 차감
- 별도 배열과 두 번의 고정 길이 반복 제거

## 3. 최종 수정 코드

```java
public class SumMissingNumbers {
    public int solution(int[] numbers) {
        int answer = 45;

        for (int i = 0; i < numbers.length; i++) {
            answer -= numbers[i];
        }

        return answer;
    }
}
```

- 프로그래머스 직접 제출 시 클래스명을 `Solution`으로 변경

## 4. 개선 결과

| 구분 | 초기 코드 | 개선 코드 |
|---|---|---|
| 주요 접근 | 0~9 배열에서 존재하는 숫자를 0으로 변경 후 합산 | 전체 합 45에서 주어진 숫자를 차감 |
| 시간 복잡도 | O(N + 20) = O(N) | O(N) |
| 추가 공간 복잡도 | O(1) — 크기 10 배열 | O(1) — 정수 변수 |

**학습 내용:**
- 고정된 범위의 전체 합에서 존재하는 숫자를 차감하여 구현 단순화
- 두 풀이의 점근적 시간·공간 복잡도 동일
- 추가 배열과 반복 작업 제거를 통한 처리 단순화
- 입력 범위와 원소 중복 여부를 확인하여 유효한 경계값 검토
