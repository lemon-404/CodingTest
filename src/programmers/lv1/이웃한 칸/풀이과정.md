# 이웃한 칸 — 코딩테스트 풀이 기록

| 항목 | 내용 |
|---|---|
| 문제 등급 | Level 1 |
| 문제 플랫폼 | 프로그래머스 |
| 문제 이름 | 이웃한 칸 / 250125 |
| 알고리즘 | 구현 |
| 입력 | `String[][] board`, `int h`, `int w` |
| 시간 복잡도 | O(1) |
| 예외 케이스 | 인접 좌표가 배열 범위를 벗어나는 경우 비교 대상에서 제외 |

**문제 정의**
1. 각 칸의 색상을 저장한 2차원 문자열 배열과 기준 좌표 `(h, w)` 제공
2. 기준 좌표의 상하좌우 인접 칸 중 같은 색상의 칸 개수 반환

**엣지 케이스**
- 인접 좌표의 행 또는 열이 0 미만인 경우 배열 접근 제외
- 인접 좌표의 행 또는 열이 `board.length` 이상인 경우 배열 접근 제외
- 행과 열이 모두 0 이상 `board.length` 미만인지 확인 후 색상 비교

**의사코드**
- `n`에 `board.length` 저장
- 행 방향 배열 `dh = {-1, 0, 1, 0}` 선언
- 열 방향 배열 `dw = {0, 1, 0, -1}` 선언
- 같은 색상 개수를 저장하는 `count`를 0으로 초기화
- `i`를 0부터 3까지 증가시키며 4방향 순회
- `checkH = h + dh[i]`, `checkW = w + dw[i]`로 인접 좌표 계산
- `checkH`, `checkW`가 모두 0 이상 `n` 미만인지 AND 조건으로 확인
- `board[h][w]`와 `board[checkH][checkW]`를 `equals()`로 비교
- 같은 색상이면 `count`를 1 증가

## 2. 문제 및 성능 분석

**복잡도:**
- 시간 복잡도: O(1) — 4방향만 탐색, 색상 문자열 길이 최대 10
- 추가 공간 복잡도: O(1) — 고정 크기 방향 배열 2개와 정수 변수 사용

## 3. 최종 수정 코드

```java
public class AdjacentCells {
    public int solution(String[][] board, int h, int w) {
        int n = board.length;

        int[] dh = {-1, 0, 1, 0};
        int[] dw = {0, 1, 0, -1};

        int count = 0;

        for (int i = 0; i < 4; i++) {
            int checkH = h + dh[i];
            int checkW = w + dw[i];

            if (checkH >= 0 && checkH < n &&
                checkW >= 0 && checkW < n) {

                if (board[h][w].equals(board[checkH][checkW])) {
                    count++;
                }
            }
        }

        return count;
    }
}
```
