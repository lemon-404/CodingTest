# 달리기 경주 — 코딩테스트 풀이 기록

| 항목 | 내용 |
|---|---|
| 문제 등급 | Lv. 1 |
| 문제 플랫폼 | 프로그래머스 |
| 문제 이름 | 달리기 경주 (178871) |
| 알고리즘 | 배열 (개선: HashMap 활용) |
| 입력 | `callings[]`, `players[]` |
| 시간 복잡도 | **초기 O(N × M) → 개선 O(N + M)** |
| 예외 케이스 | 없음 |

**문제 정의**

1. `players[]`가 달리기 경주를 한다.
2. 달리기 경주 중 선수가 앞 선수를 추월하면 해설진이 추월한 선수의 이름을 부르고(`callings`), 순위가 바뀐다.

## 1. 초기 풀이

```java
class Solution {
    public String[] solution(String[] players, String[] callings) {
        for (int i = 0; i < callings.length; i++) {
            String s = callings[i];

            for (int j = 0; j < players.length; j++) {
                if (players[j].equals(s)) {
                    String temp = players[j - 1];
                    players[j - 1] = players[j];
                    players[j] = temp;
                    break;
                }
            }
        }

        return players;
    }
}
```

## 2. 성능 문제 분석

**발생 원인**

`callings`의 각 원소마다 `players` 배열 전체를 순회하여 해당 선수를 찾는다.

- N = `players.length` (최대 50,000)
- M = `callings.length` (최대 1,000,000)
- 시간 복잡도: **O(N × M)**
- 최대 비교 횟수: 50,000 × 1,000,000 = **500억 번**

따라서 입력 크기가 최대일 때 시간 초과가 발생할 수 있다.

**개선 방향**

- `HashMap<String, Integer>`를 사용하여 선수 이름을 Key, 현재 인덱스를 Value로 저장한다.
- `map.get()`으로 선수의 인덱스를 평균 O(1)에 조회한다.
- 추월이 발생하면 HashMap의 인덱스와 players 배열의 순서를 함께 변경한다.
- 최종적으로 변경된 `players` 배열을 반환한다.

## 3. 최종 수정 코드

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public String[] solution(String[] players, String[] callings) {
        Map<String, Integer> map = new HashMap<>();

        for (int i = 0; i < players.length; i++) {
            map.put(players[i], i);
        }

        for (int i = 0; i < callings.length; i++) {
            String s = callings[i];

            int j = map.get(s);
            String temp = players[j - 1];

            map.put(s, j - 1);
            map.put(temp, j);

            players[j - 1] = s;
            players[j] = temp;
        }

        return players;
    }
}
```

## 4. 개선 결과

| 구분 | 초기 코드 | 개선 코드 |
|---|---|---|
| 선수 탐색 | 배열 순차 탐색 O(N) | HashMap 조회 평균 O(1) |
| 전체 시간 복잡도 | O(N × M) | 평균 O(N + M) |
| 추가 공간 복잡도 | O(1) | O(N) |

**학습 내용**

HashMap을 활용하면 선수의 현재 인덱스를 전체 탐색 없이 조회할 수 있다. 순위가 변경될 때 HashMap과 배열을 함께 갱신하면 탐색 성능을 개선하면서도 올바른 순서를 유지할 수 있다.
