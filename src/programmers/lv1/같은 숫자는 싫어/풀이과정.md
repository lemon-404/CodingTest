# 같은 숫자는 싫어 — 코딩테스트 풀이 기록

| 항목 | 내용 |
|---|---|

| 알고리즘 | 스택, 리스트 |
| 입력 | `int[] arr` |

**문제 정의**
1. 0~9로 이루어진 배열에서 연속된 중복 숫자 제거
2. 입력 원소의 순서를 유지한 배열 반환

## 1. 초기 풀이

**접근 방법:**
- 직전 값과 다른 숫자만 저장하여 연속 중복 제거

```java
    public static int[] solution1(int []arr) {
        int[] answer;

        Stack<Integer> stack = new Stack<>();
        int now=10;

        for (int i = 0; i < arr.length; i++) {
            if (now != arr[i]) {
                stack.push(arr[i]);
                now = arr[i];
            }
        }
        int size = stack.size();
        answer = new int[size];
        for (int i = 0; i < size; i++) {
            answer[i] = stack.get(i);
        }

        return answer;
    }

    public static int[] solution2(int []arr) {
        int[] answer;
        Stack<Integer> stack = new Stack<>();

        for (int i = 0; i < arr.length; i++) {
            if ( stack.size()==0 || stack.peek() != arr[i]) {
                stack.push(arr[i]);
            }
        }
        int size = stack.size();
        answer = new int[size];
        for (int i = 0; i < size; i++) {
            answer[i] = stack.get(i);
        }
        return answer;
    }
```

## 2. 문제 및 성능 분석

**발생한 문제:**
- 스택에서 `pop()` 수행 중 반복 조건의 크기 감소로 결과 배열 구성 및 반복 종료 문제

**원인:**
- `pop()` 호출마다 `stack.size()` 감소
- 반복 조건과 결과 배열 인덱스에 변경되는 크기 사용

**개선 방향:**
- 반복 전 스택 크기 저장
- `get(i)`로 원소를 조회하여 순서대로 배열에 저장

## 3. 최종 수정 코드

```java
import java.util.ArrayList;
import java.util.List;

public class RemoveConsecutiveDuplicates {
    public int[] solution(int []arr) {
        List<Integer> list = new ArrayList<>();
        for (int i = 0; i < arr.length; i++) {
            if (list.size() == 0 || list.get(list.size()-1)!=arr[i]) {
                list.add(arr[i]);
            }
        }
        return list.stream().mapToInt(Integer::intValue).toArray();
    }
}
```
