# 콜라 문제 — 코딩테스트 풀이 기록

| 항목 | 내용 |
|---|---|
| 문제 등급 | Level 1 |
| 문제 플랫폼 | 프로그래머스 |
| 문제 이름 | 콜라 문제 / 132267 |
| 알고리즘 | 구현, 시뮬레이션, 재귀 |
| 입력 | `int a`, `int b`, `int n` |
| 시간 복잡도 | O(K), K는 `swap` 호출 횟수 |
| 예외 케이스 | 빈 병이 `a`개 미만이거나 `a`로 나누어떨어지지 않는 경우 |

**문제 정의**

1. 빈 병 `a`개를 콜라 `b`병으로 교환.
2. 교환하고 남은 빈 병과 콜라를 마신 뒤 생긴 빈 병은 다음 교환에 사용.
3. 처음 가진 빈 병 `n`개로 교환받는 콜라의 총개수를 반환.

**엣지 케이스**

- 보유한 빈 병이 `a`개 미만이면 교환을 종료.
- 빈 병 수가 `a`로 나누어떨어지지 않으면 남은 빈 병을 다음 교환에 포함.

**의사코드**

1. 결과를 저장할 정수형 변수 `result`를 0으로 초기화한다.
2. `swap(n, a)`를 호출한다.
   - `n / a`의 몫을 `change`에 저장한다.
   - `change * b`를 `bottle`에 저장한다.
   - `n < a`이면 0을 반환한다.
   - `bottle`에 `swap(n - change * a, a)`의 반환값을 더해 반환한다.
3. `result`를 반환한다.

## 1. 초기 풀이

```java
public class ColaProblem {
    public int solution(int a, int b, int n) {
        int result = 0;

        swap(n, a);

        return result;
    }

    public int swap(int n, int a) {
        int change = n / a;
        int bottle = change * b;

        if (n < a) {
            return 0;
        }

        return bottle + swap(n - change * a, a);
    }
}
```

## 2. 문제

- `swap` 내부에서 사용하는 `b`가 메서드에 전달되지 않아 컴파일 오류 발생. `swap`의 매개변수에 `b`를 추가하고 재귀 호출에도 전달.
- `n - change * a`는 교환하고 남은 빈 병만 계산. 교환받은 콜라를 마시고 생기는 빈 병 `bottle`도 더해 다음 호출에 전달.
- `solution`에서 `swap`의 반환값을 사용하지 않아 `result`가 0으로 남는 구조. `swap`의 반환값을 바로 반환하도록 변경.

## 3. 성능 분석

- `K`는 마지막 종료 호출을 포함한 최종 풀이의 `swap` 호출 횟수.
- 호출마다 나눗셈, 곱셈, 덧셈, 조건 비교 등 고정된 횟수의 연산을 수행하므로 O(1).
- 전체 시간 복잡도는 **O(K)**.

## 4. 최종 수정 코드

**개선 의사코드**

1. `swap(n, a, b)`를 호출한다.
   - 현재 빈 병으로 교환할 수 있는 횟수 `n / a`를 `change`에 저장한다.
   - 이번에 받는 콜라 수 `change * b`를 `bottle`에 저장한다.
   - `n < a`이면 더 교환할 수 없으므로 0을 반환한다.
   - 남은 빈 병과 새로 얻은 빈 병을 합한 `n - change * a + bottle`을 다음 호출에 전달한다.
   - `bottle`과 다음 재귀 호출의 반환값을 더해 반환한다.
2. `solution`에서 `swap`의 반환값을 반환한다.

```java
public class ColaProblem {
    public int solution(int a, int b, int n) {
        return swap(n, a, b);
    }

    public int swap(int n, int a, int b) {
        int change = n / a;
        int bottle = change * b;

        if (n < a) {
            return 0;
        }

        return bottle + swap(n - change * a + bottle, a, b);
    }
}
```

**학습 내용**

- 재귀 함수의 종료 조건과 재귀 호출 구조.
- 현재 연산 결과와 다음 재귀 호출의 반환값을 합산하는 방법.
- 재귀 호출에 변경된 상태값을 정확하게 전달하는 방법.
- 메서드 내부에서 필요한 변수를 매개변수로 전달하는 방법.
- 호출한 메서드의 반환값을 결과에 반영하는 방법.
