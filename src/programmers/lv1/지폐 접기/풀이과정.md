# (PCCE 기출문제) 9번 / 지폐 접기 — 코딩테스트 풀이 기록

| 항목 | 내용 |
|---|---|
| 문제 등급 | Level 1 |
| 문제 플랫폼 | 프로그래머스 |
| 문제 이름 | 지폐 접기 / 340199 |
| 알고리즘 | 구현 / 시뮬레이션 |
| 입력 | `int[] wallet`, `int[] bill` |
| 시간 복잡도 | O(log M) |
| 예외 케이스 | 홀수 길이, 접기 없이 수납 가능, 회전 시 수납 가능, 정사각형 지폐 |

**문제 정의**

1. 지폐를 지갑에 넣기 위한 최소 접기 횟수 계산
2. 지폐가 들어가지 않으면 현재 긴 변을 반으로 접고 소수점 이하를 버림
3. 원래 방향 또는 90도 회전한 방향에서 두 변이 각각 지갑의 대응하는 변 이하이면 수납 가능

**엣지 케이스**

- 홀수 길이 → 정수 나눗셈으로 소수점 이하 버림
- 접기 없이 수납 가능 → 0 반환
- 회전해야 수납 가능 → 가로와 세로를 교차 비교
- 정사각형 지폐 → 어느 쪽을 접어도 변의 길이 조합이 같으므로 한쪽 선택

## 2. 성능 분석

- `M`은 지폐의 초기 긴 변 길이
- 접기 두 번마다 긴 변의 길이가 적어도 절반으로 감소
- 매 반복의 비교와 정수 나눗셈은 O(1), 전체 시간 복잡도는 O(log M)

## 3. 문제점 및 개선 방향

- 초기 최댓값 `n`만 관리하면 접은 뒤 어느 쪽이 더 긴지와 두 변이 지갑에 들어가는지를 판단하기 어려움
- 접을 때마다 두 변을 비교하고 더 긴 변을 갱신
- 원래 방향과 90도 회전한 방향을 모두 확인하고, 어느 한 방향으로 들어가면 종료

### 3-1. 개선 의사코드

1. 누적 접기 횟수 `result`를 0으로 초기화하고, 지갑의 가로와 세로를 각각 `x`, `y`에 저장한다.
2. `result`는 0부터 지폐가 어느 한 방향으로 지갑에 들어갈 때까지 아래 내용을 반복한다. `result`는 1씩 증가한다.
   - `bill[0] <= x && bill[1] <= y`이면 원래 방향으로, `bill[0] <= y && bill[1] <= x`이면 90도 회전한 방향으로 들어간다.
   - 어느 방향으로도 들어가지 않으면 두 변을 비교한다.
     - `bill[0] > bill[1]`이면 `bill[0]`을 2로 나눈 정수 몫으로 갱신한다.
     - 그 외에는 `bill[1]`을 2로 나눈 정수 몫으로 갱신한다.
3. 누적 접기 횟수 `result`를 반환한다.

## 4. 최종 수정 코드

```java
public class BillFolding {
    public int solution(int[] wallet, int[] bill) {
        int result = 0;
        int x = wallet[0];
        int y = wallet[1];

        while (!((bill[0] <= x && bill[1] <= y) ||
                 (bill[0] <= y && bill[1] <= x))) {
            if (bill[0] > bill[1]) {
                bill[0] /= 2;
            } else {
                bill[1] /= 2;
            }

            result++;
        }

        return result;
    }
}
```

## 5. 개선 결과

| 구분 | 초기 접근 | 최종 코드 |
|---|---|---|
| 지폐 길이 관리 | 최댓값 `n`만 관리 | `bill[0]`, `bill[1]` 관리 |
| 접는 방향 | 초기 최댓값 기준 | 매 반복마다 긴 변 비교 |
| 종료 조건 | `n`과 `x`, `y` 비교 | 회전을 포함해 양쪽 길이 비교 |
| 홀수 처리 | 2로 나누기 | 정수 나눗셈 `/= 2` |
| 접기 횟수 | `result++` | `result++` |

**학습 내용**

- 수납 가능 여부를 확인한 뒤 긴 변을 접는 순서로 시뮬레이션 구현
- 수납 가능 여부를 판정할 때 지폐와 지갑의 두 변을 각각 비교
- 접을 때마다 바뀔 수 있는 가로와 세로를 모두 관리하고 입력 배열 `bill`을 직접 갱신
- Java의 정수 나눗셈으로 홀수 길이에서 소수점 이하를 버림
