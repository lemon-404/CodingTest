# 제일 작은 수 제거하기 — 코딩테스트 풀이 기록

| 항목 | 내용 |
|---|---|
| 문제 등급 | Level 1 |
| 문제 플랫폼 | 프로그래머스 |
| 문제 이름 | 제일 작은 수 제거하기 / 12935 |
| 알고리즘 | 구현 |
| 입력 | `int[] arr` |
| 시간 복잡도 | 초기 O(N log N) → 개선 O(N) |
| 예외 케이스 | 배열의 길이가 2 미만인 경우, 최솟값의 위치 |

**문제 정의**

1. 정수 배열 `arr`에서 최솟값을 제거.
2. 나머지 요소의 기존 순서를 유지한 배열을 반환.
3. 반환할 배열이 비어 있으면 `[-1]`을 반환.

**엣지 케이스**

| 구분 | 입력 | 반환값 |
|---|---|---|
| 배열의 길이가 1 | `[10]` | `[-1]` |
| 최솟값이 처음에 위치 | `[1, 4, 3, 2]` | `[4, 3, 2]` |
| 최솟값이 중간에 위치 | `[4, 1, 3, 2]` | `[4, 3, 2]` |
| 최솟값이 마지막에 위치 | `[4, 3, 2, 1]` | `[4, 3, 2]` |

**의사코드**

1. `arr.length < 2`이면 `[-1]`을 반환한다.
2. `arr`을 오름차순으로 정렬한다.
3. 인덱스 1 이상 `arr.length` 미만에 해당하는 요소를 복사한 배열을 반환한다.

## 1. 초기 풀이

```java
import java.util.Arrays;

public class RemoveSmallestNumber {
    public int[] solution(int[] arr) {
        if (arr.length < 2) {
            return new int[]{-1};
        }

        Arrays.sort(arr);

        return Arrays.copyOfRange(arr, 1, arr.length);
    }
}
```

## 2. 문제

- 처음에는 오름차순으로 정렬된 배열을 반환하는 것으로 이해. 정렬하면 최솟값을 쉽게 제외할 수 있지만 나머지 요소의 상대 순서가 바뀜.
- 최솟값 탐색과 결과 배열 생성을 한 번에 처리하는 방법도 고려. 최솟값이 갱신될 때마다 이전 최솟값을 결과 배열에 다시 넣고 삽입 위치를 조정해야 함.
- 첫 번째 순회에서 최솟값의 인덱스를 찾고, 두 번째 순회에서 그 인덱스를 건너뛰며 나머지 요소를 원래 순서대로 복사.

## 3. 성능 분석

- `N`은 입력 배열 `arr`의 길이.
- 초기 풀이의 시간 복잡도는 정렬 O(N log N)과 부분 배열 복사 O(N)을 합쳐 **O(N log N)**.
- 최종 풀이의 시간 복잡도는 최솟값 탐색 O(N)과 결과 배열 복사 O(N)을 합쳐 **O(N)**.

## 4. 최종 수정 코드

**개선 의사코드**

1. `arr.length < 2`이면 `[-1]`을 반환한다.
2. 길이가 `arr.length - 1`인 배열 `result`를 생성한다.
3. 최솟값의 인덱스 `minIndex`를 0으로 초기화한다.
4. `i`는 1부터 `arr.length` 미만일 때까지 아래 내용을 반복한다. `i`는 1씩 증가한다.
   - `arr[i] < arr[minIndex]`이면 `minIndex`를 `i`로 갱신한다.
5. 결과 배열의 삽입 위치 `index`를 0으로 초기화한다.
6. `i`는 0부터 `arr.length` 미만일 때까지 아래 내용을 반복한다. `i`는 1씩 증가한다.
   - `i == minIndex`이면 현재 반복을 건너뛴다.
   - `arr[i]`를 `result[index]`에 저장하고 `index`를 1 증가시킨다.
7. `result`를 반환한다.

```java
public class RemoveSmallestNumber {
    public int[] solution(int[] arr) {
        if (arr.length < 2) {
            return new int[]{-1};
        }

        int[] result = new int[arr.length - 1];
        int minIndex = 0;

        // 최솟값의 인덱스 탐색
        for (int i = 1; i < arr.length; i++) {
            if (arr[i] < arr[minIndex]) {
                minIndex = i;
            }
        }

        // 최솟값을 제외한 요소 삽입
        int index = 0;

        for (int i = 0; i < arr.length; i++) {
            if (i == minIndex) {
                continue;
            }

            result[index++] = arr[i];
        }

        return result;
    }
}
```

**학습 내용**

- `Arrays.copyOfRange(arr, from, to)`는 `from` 이상, `to` 미만 범위의 요소를 새 배열로 복사한다.
- Java 배열은 길이가 고정되어 있어 요소를 제거한 결과는 새 배열에 담을 수 있다.
- 최솟값의 인덱스를 저장하면 `arr[minIndex]`로 최솟값을 확인할 수 있다.
- `continue`로 현재 반복의 나머지 동작을 건너뛸 수 있다.
- 원본의 탐색 인덱스와 결과의 삽입 인덱스를 따로 관리할 수 있다.
- 배열을 두 번 순회해도 O(N)이므로 탐색과 복사를 각각 처리할 수 있다.
