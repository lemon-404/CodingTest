# 문자열 내 p와 y의 개수 — 코딩테스트 풀이 기록

| 항목 | 내용 |
|---|---|
| 문제 등급 | Level 1 |
| 문제 플랫폼 | 프로그래머스 |
| 문제 이름 | 문자열 내 p와 y의 개수 / 12916 |
| 알고리즘 | 구현 |
| 입력 | `String s` |
| 시간 복잡도 | O(N) |
| 예외 케이스 | 대소문자 혼합, `p`와 `y`가 모두 없는 경우 |

**문제 정의**

1. 문자열 `s`에서 대소문자를 구분하지 않고 `p`와 `y`의 개수를 계산.
2. 두 개수가 같으면 `true`, 다르면 `false`를 반환. 두 문자가 모두 없으면 개수가 0으로 같으므로 `true`를 반환.

**엣지 케이스**

- 대문자 `P`와 `Y`만 있는 경우.
- 대문자 `P`와 소문자 `y`, 또는 소문자 `p`와 대문자 `Y`가 섞인 경우.
- `p`와 `y`가 모두 없는 경우.

**의사코드**

1. `pCount`와 `yCount`를 0으로 초기화하고, `s.toLowerCase()`로 문자열 전체를 소문자로 변환해 `s`에 재할당한다.
2. `i`는 0부터 `s.length()` 미만일 때까지 아래 내용을 반복한다. `i`는 1씩 증가한다.
   - `s.charAt(i)`를 `c`에 저장한다.
   - `switch (c)`에서 `'p'`이면 `pCount`를, `'y'`이면 `yCount`를 1 증가시킨다.
3. 삼항 연산자로 두 개수가 같으면 `true`, 다르면 `false`를 반환한다.

## 3. 성능 분석

- `N`은 입력 문자열 `s`의 길이.
- 전체 문자열의 소문자 변환에 O(N), 각 문자를 순회하며 개수를 세는 데 O(N)이 걸리므로 전체 시간 복잡도는 **O(N)**.
- 최대 입력 길이인 50자에서는 소문자 변환과 개수 집계가 각각 최대 50자를 처리.

## 풀이 코드

```java
public class CountPAndY {
    boolean solution(String s) {
        boolean result = false;
        int pCount = 0;
        int yCount = 0;

        s = s.toLowerCase();

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);

            switch (c) {
                case 'p':
                    pCount++;
                    break;
                case 'y':
                    yCount++;
                    break;
            }
        }

        return pCount == yCount ? true : false;
    }
}
```
