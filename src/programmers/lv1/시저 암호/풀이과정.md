# 시저 암호 — 코딩테스트 풀이 기록

| 항목 | 내용 |
|---|---|
| 문제 등급 | Level 1 |
| 문제 플랫폼 | 프로그래머스 |
| 문제 이름 | 시저 암호 / 12926 |
| 알고리즘 | 구현 |
| 입력 | `String s`, `int n` |
| 시간 복잡도 | 초기 O(N) → 개선 O(N) |
| 예외 케이스 | 공백, 알파벳 범위 초과 |

**문제 정의**

1. 문자열 `s`의 각 영문자를 `n`칸씩 이동.
2. 대소문자를 유지하며 알파벳 범위를 넘으면 처음으로 순환.
3. 공백은 그대로 유지하고 변환한 문자열을 반환.

**엣지 케이스**

- 공백은 이동하지 않음.
- 대문자에서 `Z`, 소문자에서 `z`를 넘으면 각각 `A`, `a`부터 이어서 이동.

**의사코드**

1. 빈 `StringBuilder sb`를 생성한다.
2. `i`는 0부터 `s.length()` 미만일 때까지 아래 내용을 반복한다. `i`는 1씩 증가한다.
   - `s.charAt(i)`를 `c`에 저장한다.
   - `c`가 공백이면 그대로 `sb`에 추가한다.
   - `c`가 대문자이고 `c + n > 'Z'`이거나, 소문자이고 `c + n > 'z'`이면 `c + n - 26`을 문자로 변환해 추가한다.
   - 그 외에는 `c + n`을 문자로 변환해 추가한다.
3. `sb`를 문자열로 변환해 반환한다.

## 1. 초기 풀이

```java
public class CaesarCipher {
    public String solution(String s, int n) {
        StringBuilder sb = new StringBuilder();

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);

            if (c == ' ') {
                sb.append(c);
            } else if (c >= 'A' && c <= 'Z' && c + n > 'Z') {
                sb.append((char) (c + n - 26));
            } else if (c >= 'a' && c <= 'z' && c + n > 'z') {
                sb.append((char) (c + n - 26));
            } else {
                sb.append((char) (c + n));
            }
        }

        return sb.toString();
    }
}
```

## 2. 문제

- 초기 풀이에서는 대소문자 범위와 이동 후 범위 초과 여부를 조건문에서 직접 비교.
- 대소문자는 `Character.isUpperCase()`와 `Character.isLowerCase()`로 판별.
- 기준 문자로부터의 상대 위치를 구하고 `n`을 더한 뒤, 26으로 나눈 나머지를 사용해 순환을 처리. 마지막에 기준 문자 값을 더해 원래 문자 범위로 복원.

| 구분 | 변환 공식 |
|---|---|
| 대문자 | `(c - 'A' + n) % 26 + 'A'` |
| 소문자 | `(c - 'a' + n) % 26 + 'a'` |

## 3. 성능 분석

- `N`은 문자열 `s`의 길이. 최대 입력인 8,000자에서는 반복문을 8,000회 수행.
- 두 풀이 모두 문자를 한 번씩 확인하며 각 반복의 비교와 문자 연산은 O(1). 결과의 문자열 변환까지 포함해 전체 시간 복잡도는 **O(N)**.
- 나머지 연산을 적용해 범위 초과 처리를 단순화.

## 4. 최종 수정 코드

**개선 의사코드**

1. 빈 `StringBuilder sb`를 생성한다.
2. `i`는 0부터 `s.length()` 미만일 때까지 아래 내용을 반복한다. `i`는 1씩 증가한다.
   - `s.charAt(i)`를 `c`에 저장한다.
   - `c`가 공백이면 그대로 `sb`에 추가한다.
   - `Character.isUpperCase(c)`가 참이면 `(c - 'A' + n) % 26 + 'A'`를 계산하고 문자로 변환해 추가한다.
   - `Character.isLowerCase(c)`가 참이면 `(c - 'a' + n) % 26 + 'a'`를 계산하고 문자로 변환해 추가한다.
3. `sb`를 문자열로 변환해 반환한다.

```java
public class CaesarCipher {
    public String solution(String s, int n) {
        StringBuilder sb = new StringBuilder();

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);

            if (c == ' ') {
                sb.append(c);
            } else if (Character.isUpperCase(c)) {
                sb.append((char) ((c - 'A' + n) % 26 + 'A'));
            } else if (Character.isLowerCase(c)) {
                sb.append((char) ((c - 'a' + n) % 26 + 'a'));
            }
        }

        return sb.toString();
    }
}
```

**학습 내용**

- `Character.isUpperCase()`와 `Character.isLowerCase()`로 대소문자를 판별할 수 있다.
- 나머지 연산으로 일정 범위 안에서 값이 순환하도록 구현할 수 있다.
- ASCII 값에서 기준 문자 값을 빼면 알파벳의 상대 위치가 되고, 기준 문자 값을 다시 더하면 문자 범위로 돌아온다.
- 범위의 정수 개수는 양 끝 포함일 때 `끝 - 시작 + 1`, 한쪽만 포함할 때 `끝 - 시작`, 양 끝 제외일 때 `끝 - 시작 - 1`로 계산한다. 포함 여부를 확인하면 경계에서 하나씩 어긋나는 오류를 예방할 수 있다.
