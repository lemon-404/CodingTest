# 대충 만든 자판 — 코딩테스트 풀이 기록

| 항목 | 내용 |
|---|---|
| 문제 등급 | Level 1 |
| 문제 플랫폼 | 프로그래머스 |
| 문제 이름 | 대충 만든 자판 / 160586 |
| 알고리즘 | 완전 탐색 → 배열 기반 전처리 |
| 입력 | `String[] keymap`, `String[] targets` |
| 시간 복잡도 | <span style="color:#D32F2F">**초기 O(M × T × K × L) → 개선 O(K × L + M × T)**</span> |
| 예외 케이스 | 입력 불가능한 문자 포함 시 해당 문자열의 결과를 -1로 처리 |

**문제 정의**
1. 각 키에 문자들이 순서대로 할당된 `keymap`과 입력할 문자열 배열 `targets` 제공
2. 같은 문자의 서로 다른 키·같은 키 내 중복 할당 및 미할당 가능
3. 문자 입력 횟수: 키에서의 문자 인덱스 + 1, 여러 위치에 존재하면 최솟값 선택
4. 각 타겟 문자열의 최소 누름 횟수 합산
5. 입력 불가능한 문자가 하나라도 포함된 타겟은 -1 반환

**엣지 케이스**
- 여러 키에 중복 할당: `keymap = ["AB", "BA"]`, `targets = ["B"]` → `[1]`
- 같은 키에 중복 할당: `keymap = ["ABA"]`, `targets = ["A"]` → `[1]`
- 길이 1인 문자열: `keymap = ["ABC"]`, `targets = ["C"]` → `[3]`
- 입력 불가능한 문자 포함: `keymap = ["ABC"]`, `targets = ["AD"]` → `[-1]`
- 같은 문자 반복 입력: `keymap = ["ABC"]`, `targets = ["AAA"]` → `[3]`
- 여러 타겟 독립 처리: `keymap = ["ABC"]`, `targets = ["A", "Z", "BC"]` → `[1, -1, 5]`
- 최소 크기 입력: 문제에서 허용하는 정상 입력, 별도 오류 처리 불필요

## 1. 초기 풀이

**접근 방법:**
- 타겟 문자열의 각 문자마다 모든 키와 키에 할당된 문자 탐색
- 모든 키의 일치 위치 중 최소 누름 횟수를 `minPush`에 저장
- 각 문자의 최소 횟수를 `pushSum`에 누적하여 `result[i]`에 저장
- 입력 불가능한 문자 발견 시 `pushSum = -1` 설정 후 현재 문자열 순회 종료

```java
class RoughlyMadeKeypad {
    public int[] solution(String[] keymap, String[] targets) {
        int[] result = new int[targets.length];

        for (int i = 0; i < targets.length; i++) {
            int pushSum = 0;

            for (int j = 0; j < targets[i].length(); j++) {
                char c = targets[i].charAt(j);
                int minPush = Integer.MAX_VALUE;

                for (int k = 0; k < keymap.length; k++) {
                    for (int l = 0; l < keymap[k].length(); l++) {
                        if (c == keymap[k].charAt(l)) {
                            minPush = Math.min(minPush, l + 1);
                        }
                    }
                }

                if (minPush == Integer.MAX_VALUE) {
                    pushSum = -1;
                    break;
                }

                pushSum += minPush;
            }

            result[i] = pushSum;
        }

        return result;
    }
}
```

## 2. 문제 및 성능 분석

**발생한 문제:**
- 중첩 반복에 따른 높은 시간 복잡도 및 중복 탐색
- 초기 코드의 실제 시간 초과 여부 미확인

**원인:**
- 같은 타겟 문자가 반복되어도 매번 전체 키맵 재탐색
- 타겟 배열 길이뿐 아니라 각 문자열 길이도 반복 횟수에 포함

**복잡도:**
- `M`: 타겟 배열 길이, 최대 100
- `T`: 타겟 문자열의 최대 길이, 최대 100
- `K`: 키맵 배열 길이, 최대 100
- `L`: 키맵 문자열의 최대 길이, 최대 100
- 초기 시간 복잡도: O(M × T × K × L), 모든 크기를 N으로 통일하면 O(N⁴)
- 초기 최악의 문자 비교 횟수 상한: 100 × 100 × 100 × 100 = 100,000,000회

**개선 방향:**
- 영문 대문자 26개에 대응하는 `alphabet` 배열 생성
- 키 문자열 최대 길이 100과 구분되는 미등록 값 101로 초기화
- `keymap` 순회 시 `c - 'A'` 인덱스에 최소 누름 횟수 저장
- 타겟 순회 시 배열 조회만 수행하여 누름 횟수 합산
- 값이 101인 문자 발견 시 현재 타겟을 -1로 처리하고 다음 타겟 계속 계산

## 3. 최종 수정 코드

```java
import java.util.Arrays;

public class RoughlyMadeKeypad {
    public int[] solution(String[] keymap, String[] targets) {
        int[] alphabet = new int[26];
        Arrays.fill(alphabet, 101);

        int[] result = new int[targets.length];

        for (int i = 0; i < keymap.length; i++) {
            for (int j = 0; j < keymap[i].length(); j++) {
                char c = keymap[i].charAt(j);
                int index = c - 'A';

                alphabet[index] = Math.min(alphabet[index], j + 1);
            }
        }

        for (int i = 0; i < targets.length; i++) {
            int pushSum = 0;

            for (int j = 0; j < targets[i].length(); j++) {
                char c = targets[i].charAt(j);
                int index = c - 'A';

                if (alphabet[index] == 101) {
                    pushSum = -1;
                    break;
                }

                pushSum += alphabet[index];
            }

            result[i] = pushSum;
        }

        return result;
    }
}
```

## 4. 개선 결과

| 구분 | 초기 코드 | 개선 코드 |
|---|---|---|
| 주요 접근 | 타겟 문자마다 전체 키 완전 탐색 | 키맵 전처리 후 배열 조회 |
| 반복문 구조 | 4중 반복문 | 2중 반복문 + 2중 반복문 |
| 최소 누름 횟수 | 문자를 만날 때마다 재계산 | 알파벳별 최소 횟수 저장 및 재사용 |
| 시간 복잡도 | O(M × T × K × L) | O(K × L + M × T) |
| 최악의 문자 비교·처리 횟수 상한 | 100,000,000회 | 20,000회, 배열 초기화 제외 |
| 추가 공간 복잡도 | O(1), 결과 배열 제외 | O(26) = O(1), 결과 배열 제외 |
| 결과 배열 포함 공간 복잡도 | O(M) | O(M + 26) = O(M) |
| 입력 불가능한 문자 판별 | `Integer.MAX_VALUE` 유지 | `alphabet[index] == 101` |

**학습 내용:**
- 배열 길이와 내부 문자열 길이를 함께 고려하여 시간 복잡도 계산
- 연속된 이중 반복문의 비용은 곱이 아닌 합으로 계산: O(KL + MT)
- 전처리로 문자별 최소 입력 횟수를 저장하여 중복 탐색 제거
- 대문자 A~Z를 `c - 'A'`로 배열 인덱스 0~25에 대응
- `Arrays.fill()` 초기값으로 실제 가능한 값과 구분되는 값 사용
- 입력 불가능한 문자 발견 시 현재 타겟만 실패 처리하고 다음 타겟 독립 계산
